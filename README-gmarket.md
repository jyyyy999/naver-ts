# G마켓 바로구매 (TypeScript · puppeteer-extra + Stealth · `src/gmarket/`)

`gmarket_item_stock.py` 의 재입고 감시에 **바로구매**를 붙인 판이다. `aio/node/src/lotte-test` ·
스마트스토어 판(`README.md` 의 "바로구매")과 같은 흐름이다. 크롬은 퍼피티어(Stealth)로 띄운다 —
스마트스토어 판은 그대로 Playwright 다.

```
지켜보기(크롬 감시 탭 안 fetch) → 품절→구매가능 감지 → 같은 창에 새 탭으로 구매하기(수량) → 주문서
      → 필수 동의 → [결제수단] → 결제하기 → [스마일페이 비밀번호] → 결제 완료 알림
```

**`buy.targets` 가 비어 있으면 파이썬 판처럼 재입고 알림만 보낸다.** 이 판을 돌리는 동안은
`gmarket_item_stock.py` 를 끈다 — 같은 알림을 하고, 같이 돌리면 요청이 두 배다.

## 크롬 — puppeteer-extra + Stealth, 기본은 창 없이

G마켓 상품 페이지는 Node 의 `fetch` 를 막는다 (2026-09-26 이 PC 에서 세 번 다 403). 그래서 크롬을
띄워 `item.gmarket.co.kr/robots.txt` 에 **감시 탭**을 세워 두고 그 페이지 안에서 fetch 한다 (한 번에
0.4~0.9초, HTML 한 장). 같은 출처라 로그인 쿠키가 실리고, 받아 온 HTML 의 `IsLogin` 으로 **세션이 살아
있는지도 매 조회마다 덤으로 안다.** 사는 일은 같은 크롬에 **새 탭**을 열어서 한다.

크롬은 `puppeteer-extra` + `puppeteer-extra-plugin-stealth` 로 띄운다 (`src/gmarket/launch.ts`). Stealth 가
자동화 흔적(`navigator.webdriver`, `HeadlessChrome` UA …)을 지우고, 언어는 `ko-KR` 로 맞춰 끼운다 (그대로
두면 en-US 로 나간다). **기본은 창 없이**(`buy.headless: true`) 돈다.

**사람이 봐야 하는 일은 창에서 한다.** 창 없는 크롬은 창으로 바꿀 수가 없어서, 그 순간 **쿠키째 들고 보이는
창으로 다시 띄운다** (1~2초). 한 번 띄우면 그 실행 동안은 창을 둔다.

| 언제 | |
|---|---|
| Cloudflare 봇 확인이 떴을 때 | 창을 띄워 사람이 마치기를 기다린다 (아래) |
| 사기 시작할 때 | 사는 탭은 **늘 창에** 연다 — 어디서 멈췄든 사람이 이어 누르고, 결제는 그 탭에서 끝난다 |
| `--login` | 늘 창에서 |
| `--buy` · `--dump-pay` | 처음부터 창으로 띄운다 |

드랍처럼 1초가 아까우면 `--show`(또는 `"headless": false`)로 처음부터 창을 띄워 둔다 — 사는 순간 다시
띄우는 1~2초가 없다. `--drop` 을 창 없이 켜면 그렇게 하라고 알려 준다.

**Stealth 가 봇 확인을 막아 주지는 못한다.** 2026-09-28 에 이 PC 에서 창 없는 Stealth 크롬으로 상품 하나를
읽었더니 **첫 조회부터 봇 확인이 떴다** (그 전 판 — Playwright, 보이는 창, UA 그대로 — 은 09-26 23:18 에
봇 확인 없이 읽었다. 그사이 이 IP 가 찍힌 것인지, 창 없는 크롬이라 걸린 것인지는 가려 보지 않았다 — 확인이
뜬 뒤에 더 두드리지 않았다). 그 확인은:

```
HTTP 403 · "잠시만 기다리십시오…" · cType: 'managed' (Turnstile)
"고객님의 사이트 내 활동이 봇의 동작과 유사해 보입니다."
"고객님들의 원활한 쇼핑을 위해 현재 간단한 봇 확인 절차가 진행되고 있습니다."
```

## 봇 확인이 뜨면

**프로그램은 확인 화면을 누르지 않는다.** 대신:

- 품절·일반 403 과 따로 알아본다. 품절로 읽어 "한발 늦었다" 로 넘기지 않는다.
- **다시 두드리지 않는다** — 두드리는 것 자체가 "봇의 동작" 으로 읽힌다.
- 디스코드로 알리고(멘션), (창 없이 돌았으면 창을 띄워) 그 화면을 창 맨 앞에 띄워 **사람이 직접 마치기를
  기다린다** (`bot_check_wait_seconds`, 기본 300초). 감시 탭과 사는 탭이 같은 크롬(같은 쿠키)이라 한 번
  마치면 둘 다 이어간다. 창을 다시 띄울 때 마친 표시(`cf_clearance` 쿠키)도 들고 간다.
- 마치면 이어가고, 그 뒤로는 **주기를 두 배로 늦춘다**(최대 60초, 이번 실행 동안). 안 마치면 5분 → 10 …
  60분 물러난다.
- 사려는 순간 떴는데 안 마쳤으면 "바뀌는 순간" 을 아껴 둔다 — 뒤늦게라도 마치면 다음 조회에서 산다.

`--drop`(1초 주기)은 봇 확인을 부르기 쉽다. 드랍 직전에만 켠다. 파이썬 판(curl_cffi)은 이 확인을 넘을 수
없어서, 확인이 켜져 있는 동안은 403 으로 물러나기만 한다.

## 준비

`ts` 폴더에서 한다. `npm install` 이 `puppeteer` · `puppeteer-extra` · `puppeteer-extra-plugin-stealth` 를
받는다 (스마트스토어 판은 그대로 Playwright 다). 크롬은 퍼피티어가 받아 두는 것(`~/.cache/puppeteer`)을 쓰고,
없으면 설치된 Google Chrome → Edge 로 대신 띄운다. 받으려면 `npx puppeteer browsers install chrome`.

```bash
.\gm --login
```

창이 뜨면 **직접** 로그인한다 ('로그인 상태 유지' 를 켜 두면 오래 간다). 프로그램은 아이디·비밀번호를
넣지 않고, 로그인이 되면 쿠키만 `../gmarket_session.json` 에 저장한다. 이 파일은 남과 공유하면 안 된다
(`.gitignore` 에 넣어 뒀다).

로그인 화면을 벗어나면 확인용 탭이 하나 더 열려 상품 페이지로 로그인됐는지 본다 (메인에는 그 표시가 없다).
알아보면 "로그인 확인" 이 뜨고 저절로 저장된다. **안 뜨면 터미널에서 Enter** — 그때 저장한다.

> 세션 파일의 꼴은 Playwright 판과 같다 (`{cookies, origins}`). Playwright 판으로 로그인해 둔
> `gmarket_session.json` 은 그대로 읽힌다 — 다시 로그인할 필요 없다.

```bash
.\gm --whoami
```

```bash
.\gm --add https://item.gmarket.co.kr/Item?goodsCode=4856436280
```

## 실행

```bash
.\gm
```

루트의 `run-gmarket-buy.bat` 을 더블클릭해도 된다. **파워셸에서는 `.\gm` 으로 부른다** —
`npm run gm -- --pin 1234` 는 파워셸이 `--` 를 지워 npm 이 `--pin` 을 가져간다 (스마트스토어 판의 `ss.cmd` 와 같은 이유).

| | |
|---|---|
| `.\gm` | 지켜보다가 열리면 산다 |
| `.\gm --drop` | 드랍 모드 — 1초(±0.2) 주기, 재시도 쉼 없음 |
| `.\gm --link [주소]` | 클립보드(또는 준) 상품 하나만 이번 실행의 대상으로 삼고 곧장 감시 |
| `.\gm --buy [주소]` | 지금 바로 산다 (품절이면 창을 안 띄운다) |
| `.\gm --dump-pay [주소]` | `--buy` 와 같되 결제하기 뒤 화면을 `../gmarket-pg-dump.txt` 에 받아 적는다 |
| `.\gm --status [주소…]` | 지금 재고·가격·구매 한도·로그인 여부 |
| `--show` | 크롬을 처음부터 창으로 띄운다 (`buy.headless` 를 이번만 끈다). 드랍이면 같이 준다 |
| `--action open\|agree\|submit` | 이번만 어디까지 갈지 |
| `--no-buy` · `--once` · `--dry-run` | 알림만 / 한 바퀴만 / 사지도 보내지도 적지도 않고 |
| `--reset` | 산 기록을 지운다 |
| `--pin [비밀번호]` | 스마일페이 비밀번호 저장 (값 없이 = 클립보드, `clear` = 지우기) |
| `--login` · `--whoami` · `--test` | 로그인 / 세션 확인 / 웹훅 시험 |

감시 중에 다른 창에서 `.\gm --login` 을 다시 하면 **감시를 끄지 않아도 새 세션으로 갈아탄다.**

## 설정 — `../gmarket_config.json` 의 `"buy"` 칸

파이썬 판과 같은 파일이다. 파이썬 판이 쓰는 칸(`products`·`discord_webhook_url`·`item_interval_seconds`·
`item_jitter_seconds`·`item_cooldown_minutes`·`restock_mention`)은 그대로 같이 읽고, 사는 데 필요한 것만
`"buy"` 칸에 모았다. 파이썬 판은 이 칸을 모르고 지나간다.

```json
"buy": {
  "targets": [
    "https://item.gmarket.co.kr/Item?goodsCode=4856436280",
    { "url": "https://item.gmarket.co.kr/Item?goodsCode=4844939494", "ea": 2, "max_price": 10000 }
  ],
  "order_action": "submit",
  "pay_method": [],
  "pay_method_mark": "",
  "pg_password": "",
  "buy_on_restock_only": true,
  "max_buys_per_run": 1,
  "cooldown_minutes": 30,
  "bot_check_wait_seconds": 300,
  "headless": true
}
```

살 상품은 `products` 에 따로 적지 않아도 감시 목록에 들어간다.

| 칸 | 기본 | |
|---|---|---|
| `targets` | `[]` | 주소 한 줄, 또는 `{url, ea, option, max_price, label}` |
| `order_action` | `submit` | 아래 표 |
| `pay_method` | `[]` | 고를 결제수단 (한 줄이 한 단계, `\|` 로 여러 이름). **비우면 건드리지 않는다** — 주문서에 이미 골라져 있는 것으로 간다 |
| `pay_method_mark` | `""` | 고른 뒤 화면에 보여야 하는 글자. 안 보이면 결제하기를 안 누른다 |
| `pg_password` | `""` | 스마일페이 비밀번호. `GMARKET_PG_PASSWORD` 환경변수가 먼저다 |
| `buy_on_restock_only` | `true` | 품절 → 구매가능 으로 **바뀌는 순간**에만 산다 |
| `max_buys_per_run` | `1` | 이만큼 데려오면 감시를 멈춘다 |
| `cooldown_minutes` | `30` | 한 번 시도한 상품은 이만큼 쉰다. 품절로 진 것(한발 늦음)은 세 번까지 안 쉰다 |
| `bot_check_wait_seconds` | `300` | Cloudflare 봇 확인이 떴을 때 사람이 창에서 마치기를 기다리는 시간 (감시·구매 공통) |
| `headless` | `true` | 크롬을 창 없이 띄운다. 봇 확인·사기 때는 창으로 다시 띄운다 (1~2초). `false` = 처음부터 창 |
| `drop_interval_seconds` · `drop_jitter_seconds` | `1` · `0.2` | `--drop` 의 걸음 |
| `max_price` | `0` | 이보다 비싸면 안 산다 (0 = 상한 없음) |
| `max_attempts` · `retry_delay_seconds` | `2` · `1` | 주문서까지 못 갔을 때 다시 해 보기 |
| `browser_timeout_seconds` | `20` | 한 화면을 기다리는 시간 |
| `pg_dump` | `true` | 어긋났을 때 결제하기 뒤 화면을 받아 적는다 |
| `paid_wait_minutes` · `paid_markers` | `10` · (주문완료 문구·`/complete`) | 결제 완료를 지켜보다 디스코드로 "successfully checkout" |
| `notify` | 전부 | `opened` · `blocked` · `session` · `paid` 중 보낼 것 |

**어디까지 가나 — `order_action`**

| | |
|---|---|
| `"submit"` (기본) | 필수 동의 → 결제하기 → **비밀번호 자판 앞에서 멈춘다.** 비밀번호는 사람이 넣는다 |
| `"submit"` + `pg_password` | 자판까지 누른다 — **사람 손 없이 결제가 끝난다** |
| `"agree"` | 주문서에서 필수 동의까지 하고 멈춘다 |
| `"open"` | 주문서를 열어 두고 멈춘다 |

**필수 동의만 체크한다.** 옆 글에 "필수" 나 "(결제|구매|주문) … 동의" 가 있고, 선택·광고·마케팅·수신·혜택·
이벤트가 없는 것만. 롯데온 주문서의 "이 결제수단을 다음에도 사용"·"안심번호 사용" 같은 것은 안 건드린다.

**비밀번호**는 로그·덤프에 남기지 않는다(자릿수만). 틀리면 다시 넣지 않는다 — 몇 번 틀리면 잠긴다.
**같은 키를 두 번 누르지 않는다** — 눌렀는데 비밀번호 칸(점)이 안 늘면 다시 누르지 않고 물러난다
(롯데온 판이 점을 잘못 읽어 같은 키를 또 누르다 틀린 비밀번호가 쌓인 적이 있다).

## 알아 둘 것

- **구매 한도를 먼저 본다.** 상품 페이지의 `OrderPossibleCnt`(`30일당 1개 (구매가능 : 1개)`)를 읽어
  `ea` 를 거기까지 깎고, 0 이면 사지 않는다. 수량 증가를 넘겨 누르면 사이트가 alert 로 막는데, 그때도
  거기서 멈추고 그 수량으로 간다.
- **로그인이 풀리면 감시는 계속하고 사지 않는다.** 디스코드로 알린다. 그 사이 열린 상품은 "바뀌는 순간" 을
  아껴 두었다가, 다시 로그인하면 곧장 산다.
- **구매하기는 한 번만 누른다.** 사이트는 담는 중에 또 누르면 "장바구니에 담는 중입니다" alert 를 띄운다.
- **상품 페이지가 403(차단 화면 "G마켓 - 쇼핑을 바꾸는 쇼핑")이면 품절로 읽지 않고 1초 뒤 한 번 더 연다.**
  처음엔 쉬지 않고 네 번 열었는데, 그렇게 두드리는 것이 봇 확인을 부르는 짓이라 줄였다.
- **사는 탭은 닫지 않는다.** 결제는 그 탭에서 끝난다. 감시가 끝나도 사는 탭이 열려 있으면 사람이 닫을 때까지
  창을 살려 둔다 (Ctrl+C 를 누르면 창째로 끝난다). 감시 탭은 닫아도 다음 조회에서 다시 연다.
- **탭이 열리자마자 닫혀도 죽지 않는다.** Stealth 는 새 탭에 스크립트를 심다가 탭이 닫히면 받는 이 없는 오류를
  남기는데, Node 는 그걸로 프로세스를 끝낸다 (가짜 페이지 시험에서 실제로 죽었다 — 스스로 닫히는 결제 팝업이면
  결제 중에 죽는다). `launch.ts` 가 **닫힌 탭 오류만** 파일 로그로 돌린다.
- **받아적기는 글 넣는 칸의 값을 적지 않는다** (자리 표시와 글자 수만). 예전 판은 받는 분·주소 칸의 값을 그대로
  적었다 — 이 판을 옮기며 가짜 페이지 시험에서 드러나 고쳤다.
- 로그는 `../gmarket-buy.log`, 산 기록은 `../gmarket_buy_state.json` (파이썬 판의 `gmarket_item_state.json`
  과 따로다). 구매 흐름의 세부(DEBUG)는 파일에만 남는다 — 화면에도 보려면 `SMARTSTORE_DEBUG=1`.
